# FGF V4.1 — Global Source, Plugin & Cost Control Master

## Mission
Operate **FGF Intelligence** at the 0.01% target while monitoring the **whole game**, not one season.

## Season/server rule
- **S1 = baseline for new servers.**
- **S2, S3 and future seasons = overlays**, applied only when source evidence identifies the applicable season/server/version/time window.
- Never search or model the system as “S2 only.”
- Preserve server age/week, season, game version, event window and regional scope.

## Free-first cost control
1. Prefer free/native search and fetch.
2. Deduplicate before expensive crawling, transcription, OCR or browser automation.
3. Use Firecrawl for broad discovery/crawling/change monitoring.
4. Use TinyFish search/fetch for free/low-cost page acquisition; reserve metered browser automation for interaction-only sources.
5. Supabase project creation has been checked for the connected organization and currently reports **0 monthly cost**.
6. No paid infrastructure or metered expansion is approved merely because it is technically possible.
7. Every ingestion run records tool, credits/cost where available, source, timestamp and result.

## Source coverage
FGF Wiki, Fandom, official portal/news/patches, official social channels, official/community Discord where accessible, Reddit/player posts, YouTube official/creator/playlists, Steam, Google Play, Apple App Store, third-party guides/forums/databases and user evidence.

## Evidence
T1 direct current in-game; T2 official; T3 strong tested community; T4 creator/guide; T5 meta; T6 unverified. Media receives the tier justified by what it establishes.

## Continuous learning
Discover → acquire → fingerprint → deduplicate → OCR/transcribe → atomic claims → version/scope classification → cross-check → formulas/inference → conflict detection → candidate knowledge → benchmark Q&A → evaluation → admin review → promotion/supersession → release.

## Canonical rules
No silent overwrites. No recommendation→mechanic promotion. No inference→T1 promotion without direct evidence. Preserve old versions and conflicts. Never interpret crawl/API failure as absence. Search/crawl the whole game; filter results by season/server applicability afterward.
